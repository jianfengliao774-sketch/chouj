# 已购买号码展示修复

2026-09-08：`我的参与` 中原先只显示每笔购买的份数、金额和交易链接。服务器已经返回 `TicketsAllocated` 的实际分配 bitmap，页面遗漏了解码展示。

每笔交易现在提供默认折叠的“查看号码”，展开后显示完整五位号码，并可复制全部。号码区固定为 160px 高，内部滚动，不可拖大；5000 个号码也不会撑长页面。展开时才解码，使用一个只读文本框显示完整列表。自动刷新保留展开状态及滚动位置，切换钱包或查询地址时隔离状态；同时支持手机、中英文及剪贴板不可用时的手动复制。

号码只来自实际已确认事件：40 个 uint256、每词最低位对应最小号码；合约索引 0 对应 00001，9999 对应 10000，末词仅低16位合法。使用 BigInt，严格核对实际分配数；缺失或不一致时提示暂不可用，不根据申请份数或自选号推算。部分成交显示实际买到的号码。

验证包括位边界、5000 个完整号码、部分成交、非法或缺失记录、同一期多笔购买、复制与失败回退、自动刷新、账户切换、语言切换以及窄屏尺寸。公开1000份购买样本与链上成功回执、实际分配数量相符。所有交互测试均使用模拟账户，不需要真实签名或交易。

回归入口：`pnpm test` 与 `node test/bem-purchased-ticket-numbers.browser.mjs`。浏览器脚本支持 `PLAYWRIGHT_MODULE`、`CHROME_PATH` 和 `DIST_DIR`，拦截全部外部请求。

后端事件、合约、份额和购买流程沿用现行实现；本次发布只更新前端源文件和静态构建资源。

最终布局实测：桌面、390px 手机和 320px 窄屏，号码区均高160px，整个折叠区展开高276.5px，5000号码在区内滚动，页面无横向溢出。
