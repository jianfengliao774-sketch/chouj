# 自动退款查询与期号显示

退款卡片连接钱包后自动查询当前场次全部可领取本金，不要求输入合约期号。接口先对完整钱包记录计算汇总，再分页显示历史，因此页面之外的期次也包含在可领金额内。提交前重新读取，收款人为当前连接钱包。钱包或场次切换后，旧请求不能继续提交。

沿用已部署的 `refundMany`，单笔最多 64 期；多于 64 期优先选择即将到期的期次，再将入参按合约要求升序排列。一批只有一次 BEM 转账，剩余期次可继续领取。没有可领取记录、账户切换、索引暂时不可用不会提交空领取交易。

页面期号采用 `YYYYMMDDNNNN`，例如 `202609070001`。按每个场次的 UTC 开盘日期分别从 0001 编号，跨日以 UTC 00:00 为准；同一期在中英文页面使用相同编号。合约累计 roundId 保留，用于交易、事件和历史查询。已确认记录依据链上开盘时间；实时状态在索引尚未追上时，按固定区块读取历史轮次确定当日序号。尚未首次购买的轮次是当前 UTC 日期的预编号，实际开盘后固定。

页面时钟、购买记录和销毁记录：中文显示北京时间 UTC+8，英文显示 UTC+0。倒计时仍基于区块时间和秒数，不因语言改变。后台每日完成数量按 UTC 日统计，明确标注统计时区。

用户端没有连接钱包手动开奖入口；只保留后台开奖结果的卷轴展示、回放和领取奖金。私钥导入配置见 `sparkdraw-automation.md`。
