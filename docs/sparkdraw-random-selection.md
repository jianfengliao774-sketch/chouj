# 网页随机选号

2026-09-07：按用户要求保留现有五个 V5 合约，不部署或切换新合约。自动模式改为「随机选号」，自由选号保持原规则。

网页在授权完成后，按同一区块读取当前期号、钱包份额及全部 556 个号码存储字。每个存储字含 18 个 14 位持有人编号，0 表示未售；末尾超出 10,000 的槽位不参与。使用浏览器 crypto.getRandomValues、拒绝取模偏差与部分 Fisher–Yates 洗牌，从未售号码中等概率、不重复取样。数量不超过请求份数、钱包本期剩余额度及实际未售数量。

取样后按合约要求升序编码，通过已有 buySelected 购买。排序只影响编码，不改变抽样集合。不使用旧 buy 的连续分配路径，也不因 RPC 失败回退成连续号段。钱包、页面选择或期号变化会停止本次提交。领取、退款、开奖随机数与后台自动执行均保持现有合约规则。

网页读取与链上成交之间仍可能有其他交易。冲突号码由现有合约向后补号并在末尾回绕；最终以 TicketsAllocated 与 PurchaseResult 为准。接近售罄时，仅剩的号码可能相邻，网页不承诺号码永远分散。浏览器选号不参与生成开奖结果。

验证：随机选取 5,000 份的唯一性、占用过滤、存储边界、取模拒绝、余量不足、买入入口、钱包与期号变化；线上只读核对 ticketWords 和发布资源。未发送测试购买交易。
