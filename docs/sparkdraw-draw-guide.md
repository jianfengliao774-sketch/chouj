# 开奖说明页面

入口：/draw-guide.html。首页与销毁页导航提供“开奖说明”，支持中文/英文；时间分别使用北京时间与 UTC+0。

正式版只介绍 5 / 10 / 50 BEM 场次。页面解释巨兽 2075 电路与 drand 的作用、购买至领奖的流程、退款销毁期限。普通说明优先，计算参数放在展开详情。

构建时从 profiles 与部署清单生成三个正式场和共用验证器的地址、部署交易/区块哈希、运行代码 Keccak-256；身份不一致则构建失败。电路网表哈希直接取固定编译输入。公开 current-contracts.json 只包含这四份部署，另有源码标准输入与 SHA-256 下载校验。

查询仅 GET 已有 records API，无钱包调用。可填网站期号或合约内部期号；不能把网站期号直接用于链上 rounds()。读取失败和索引未找到明确区分。网站公开记录按正式场过滤；真实链上历史不会被删除。

Vite 多页入口、服务端静态白名单、手机布局和中英文切换应一并验证。正式版关闭公共部署页面。此次无需修改合约。
