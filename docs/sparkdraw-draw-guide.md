# 开奖说明页面
入口：`/draw-guide.html`。首页与销毁页导航提供“开奖说明”；支持现有中文/英文偏好。中文时间使用北京时间，英文使用 UTC+0。

## 内容与数据来源
- 明确使用 **巨兽 2075 电路 / BEHEMOTH Circuit #2075**，区分 drand 随机来源、电路确定性计算和网页展示。
- 流程、拒绝采样、按实收分配、24 小时领取、12 小时退款公示和现役 V5 边界。
- 构建时从当前 profiles 与 deployed-contracts.json 生成五场次与验证器的完整地址、部署交易/区块哈希、runtime Keccak-256；身份不一致则构建失败。
- 电路地址/netlist 哈希直接取发布标准输入；另列 BEM、容器、dead 地址、drand 网络哈希、源码文件 SHA-256 与下载链接。
- 查询仅 GET 已有 records API，可输入网站展示期号或场次内部 roundId。显示索引已确认数据、证明/签名和交易链接，不调用钱包或发送交易。
- 网站展示期号不能直接传给合约 rounds(roundId)。页面介绍给出独立核验步骤与历史 round 2 → 01000 示例。
- 公开资料中的快照区块不是实时状态，也不代表 BscScan 已完成源码验证。

## 发布
新增 HTML 必须同时进入 Vite 多页入口与服务端静态路由白名单。网站构建、静态资源、期号查询与手机排版检查均应完成。无需重新部署合约。
